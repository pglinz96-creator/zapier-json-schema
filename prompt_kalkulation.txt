KALKULATION DURCHFÜHREN:

1. Berechne den Materialbedarf: Auflage + 10% Makulatur (Mindeststückzahl 50 Bogen)
2. Berechne Papierkosten auf Basis Format und Grammatur
3. Berechne Druckkosten (Rüstkosten + laufende Kosten)
4. Berechne Veredelungskosten falls zutreffend
5. Berechne Layoutkosten falls keine Druckdaten vorhanden
6. Addiere alle Kosten = Selbstkosten
7. Berechne Verkaufspreis netto mit Aufschlag 72.4% auf Selbstkosten (entspricht 42% Marge auf Verkaufspreis)
8. Berechne MwSt. 8.1% auf Verkaufspreis netto = Verkaufspreis brutto
9. Runde Verkaufspreis netto auf CHF 5.– auf
10. Berechne beide Margen-Kennzahlen (s.u.)
11. Prüfe Optimierungsmöglichkeiten

MARGENBERECHNUNG (beide Kennzahlen ausgeben):

Aufschlag auf Selbstkosten (Aufschlagsmarge):
  marge_auf_selbstkosten_prozent = (Verkaufspreis netto - Selbstkosten) / Selbstkosten × 100
  Beispiel: Selbstkosten CHF 100, Verkaufspreis CHF 172.40 → Aufschlag = 72.4%

Marge auf Bruttoverkaufspreis (Handelsmarge):
  marge_auf_verkaufspreis_prozent = (Verkaufspreis netto - Selbstkosten) / Verkaufspreis netto × 100
  Beispiel: Selbstkosten CHF 100, Verkaufspreis CHF 172.40 → Handelsmarge = 42.0%

Beide Werte auf eine Dezimalstelle runden und im JSON ausgeben.
